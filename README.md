# Personal Portfolio App UI Design

## Project Objective
Design a modern and responsive portfolio application UI with user-friendly layouts for mobile and desktop.

## Tools Used
- Figma (wireframes, UI design, prototype)
- Canva / Icons (optional)

## Design Workflow
1. Researched modern portfolio design inspirations
2. Created low-fidelity wireframes for all screens
3. Designed high-fidelity UI screens in Figma
4. Built responsive layouts for mobile and desktop
5. Applied typography, color palette, and icons
6. Created a clickable prototype for navigation flow
7. Prepared screenshots and documentation
